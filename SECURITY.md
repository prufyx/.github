# Security policy

## Report a vulnerability

Email [hello@prufyx.com](mailto:hello@prufyx.com) with the affected repository, version or commit, impact, and a minimal reproduction.

Do not open a public issue for a suspected vulnerability. Do not send credentials, Kubernetes Secrets, production snapshots, raw customer objects, or other sensitive data. We will arrange a safer transfer method if evidence is required.

Prufyx is in early development and does not yet publish a response-time SLA. We will acknowledge reports as soon as practicable and coordinate disclosure after impact and remediation are understood.

## Scope

Each repository states its supported status. Architecture documents, examples, fixtures, and planned capabilities are not production security controls.
