# Contributing to Prufyx

Prufyx repositories are opening in stages. Before contributing:

1. Read the target repository's status, scope, license, and contribution notes.
2. Open an issue or discussion before substantial work so the problem and evidence can be agreed.
3. Keep compatibility claims atomic, source-linked, configuration-aware, and testable.
4. State what is fact, reproduced evidence, inference, hypothesis, or unknown.
5. Never submit customer data, production snapshots, credentials, Secrets, proprietary configuration, or unlicensed source material.

Small, focused changes with a falsifiable test are easiest to review. A contribution is not accepted until its repository-specific review and contribution terms are satisfied.
