## Community release review

Prufyx Community source, downloads, contribution instructions, and demo instructions are temporarily unavailable while the product, security, and publication boundaries are reviewed.

The recorded alpha implemented one bounded declared-mode check for exact Prometheus inputs. Its scoped results did not establish process startup, applied runtime mode, data safety, remote-write behavior, rollback, or whole-upgrade compatibility.

We will publish an updated release status when the review is complete.
