# Support

- Use a public issue for a reproducible bug in a public Prufyx repository.
- Use [hello@prufyx.com](mailto:hello@prufyx.com) for private-preview and design-partner questions.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Do not attach credentials, Secrets, production snapshots, customer data, or sensitive logs to public issues.

Prufyx is in early development. Unless a repository says otherwise, public artifacts do not carry production support, availability, compatibility, or response-time commitments.
